# Витрина проектов (Frontend)

Клиентская часть платформы «Центр проектной деятельности». Приложение для отображения витрины проектов, биржи задач и личного кабинета студента.

## 🛠 Стек технологий

* **React 18**
* **TypeScript**
* **Vite** (Сборщик)
* **Tailwind CSS** (Стилизация)
* **React Router DOM** (Маршрутизация)
* **Axios** (HTTP-клиент для запросов к API)
* **Lucide React** (Иконки)

## 🚀 Как запустить проект

### Требования
Убедитесь, что у вас установлен **Node.js** версии 18 или выше.

### Шаги установки

1. Перейдите в папку с фронтендом (обратите внимание на вложенность папок, если репозиторий был склонирован как есть):
   ```bash
   cd showcase-frontend
2. Установите зависимости:
   ```bash
   npm install
3. Создайте файл .env в корне проекта (рядом с package.json) и добавьте в него адрес бэкенда(позже будет)
4. Запустите сервер разработки
   ```bash
   npm run dev
5. Откройте приложение в браузере:
👉 http://localhost:5173
